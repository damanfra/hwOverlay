# HwOverlay.Native

Reescrita em C++ do [HwOverlay](https://github.com/damanfra/hwOverlay): overlay minimalista de monitoramento de
hardware para Windows, com gauges de temperatura e uso de CPU, GPU, RAM e disco. Meta: a versão mais leve e de
mais baixo nível possível, sem exagero.

**Status: só planejamento.** Nenhum código ainda. Veja [PLANO.md](PLANO.md).

Projeto pessoal. Textos de UI, comentários e commits em português (pt-BR).
